# ====== ENTRADAS / RESERVADOS ======
GPIO35 - EMERGENCY_STOP (entrada digital, solo lectura) - Pull externo
GPIO34 - VFD_FAULT (entrada digital, solo lectura) - Pull externo

GPIO0  - RES_IN1 (reservado, entrada digital) - strapping pin (no usar como salida)
GPIO2  - RES_IN2 (reservado, entrada digital) - strapping pin (no usar como salida)
GPIO15 - RES_IN3 (reservado, entrada digital) - strapping pin (no usar como salida)

# Notas:
# - NO usar GPIO12 por conflictos de arranque del ESP32.
# - Relés activos en HIGH; reposo en LOW.
